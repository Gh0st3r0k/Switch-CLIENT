# FIIT-STU-PSIP-PROJECT-CLIENT

Semestral project — FIIT STU, subject: PSIP

---

## 📚 Project Description

This is the **client-side** of the semestral project built with **Electron**.

The application provides:
- User login interface.
- Real-time network port monitoring.
- MAC address table visualization and management.
- Port traffic statistics.
- Application settings management (e.g., device name, MAC table TTL).

It communicates with the **backend server** via REST API on [`http://localhost:5215`](http://localhost:5215).

---

## 🚀 How to Run

1. Make sure the **server** is running first: [`Switch-SERVER`](../server/README.md).
2. Install dependencies (if needed):
    npm install
3. Start the Electron app:
    npm start
